# Контекст проекта FAAS

## Что это

Русскоязычный презентационный сайт FAAS — «Федерация воздушно-спортивного многоборья». Тематика: соревнования по пол-спорту, воздушному кольцу и воздушным полотнам. Сейчас это в основном статический UI-прототип с демонстрационными данными.

## Технологии

- React 18 + TypeScript
- Vite 6
- React Router 7
- Tailwind CSS 4
- `motion` для анимаций
- `lucide-react` для иконок
- UI-заготовки Radix/shadcn находятся в `src/app/components/ui/`
- Команда разработки: `npm run dev`; production-проверка: `npm run build`

## Структура страниц

- `/` — главная: hero-блок, ближайшие соревнования, новости, преимущества федерации и последние отчёты.
- `/calendar` — календарь соревнований и карточки мероприятий.
- `/reports` — отчёты о прошедших мероприятиях, фотографии, результаты и победители.
- `/participation` — документы и инструкции для участников.
- `/about` — миссия, ценности, команда, партнёры и контакты.
- Остальные маршруты показывают `NotFound`.

Общий layout с навигацией, мобильным меню, логотипом и футером расположен в `src/app/components/Layout.tsx`; маршруты — в `src/app/routes.tsx`.

## Текущее состояние и важные ограничения

- Контент в основном захардкожен внутри файлов страниц; backend, CMS и API не подключены.
- Изображения мероприятий и команды загружаются с Unsplash.
- Скачивание документов пока имитируется `alert`/`console.log`; PDF-файлов в проекте нет.
- Кнопки таблиц результатов, галерей, повторов трансляций и соцсетей пока являются UI-заглушками; часть ссылок ведёт на `#`.
- Контактные данные и имена команды выглядят как демонстрационный контент и требуют проверки перед публикацией.
- `index.html` всё ещё содержит общий title `Sports Federation Website`, его стоит заменить на брендовый.

## Рабочие ориентиры

При дальнейших изменениях сначала проверять соответствующую страницу в `src/app/pages/`, общую оболочку — в `src/app/components/Layout.tsx`, а стили — в `src/styles/`. После заметных изменений запускать `npm run build`.
